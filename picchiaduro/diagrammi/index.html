    Diagrammi di Sequenza

    Sequenza 1 — Rilevamento collisione in Smash Ultimate

    sequenceDiagram
  participant G as Giocatore
  participant CG as Client di Gioco
  participant HC as Gestore Hitbox
  participant PG as Personaggio Attaccante
  participant PE as Personaggio Difensore

  Note over G, CG: Giocatore esegue un input di attacco

  G->>CG: InputAttacco(mossa)
  activate CG
  CG->>PG: EseguiAnimazione(mossa)
  activate PG
  PG-->>CG: SpawnHitbubble(posizione, raggio R1)
  deactivate PG

  CG->>HC: VerificaCollisione(hitbubble, hurtbox)
  activate HC
  HC->>HC: CalcolaDistanza(centroAttacco, centroDifensore)

  alt D < R1 + R2
    HC-->>CG: ColpoValido(danno, knockback)
    CG->>PE: ApplicaDanno(danno)
    CG->>CG: MostraEffettoImpatto()
  else D >= R1 + R2
    HC-->>CG: ColpoMancato()
  end

  deactivate HC

  opt Mossa troppo rapida — rischio bullet-through-paper
    CG->>HC: InterpolaSfere(frameCorrente, framePrecedente)
    activate HC
    HC->>HC: GeneraSfereAffiancate()
    HC-->>CG: ParetiContinuaCreata()
    deactivate HC
  end

  deactivate CG

    Sequenza 2 — Rilevamento collisione in Tekken 8

    sequenceDiagram
  participant G as Giocatore
  participant CG as Client di Gioco
  participant SK as Gestore Scheletro 3D
  participant HC as Gestore Hitbox
  participant AV as Avversario

  Note over G, CG: Giocatore esegue un attacco in spazio 3D

  G->>CG: InputAttacco(mossa)
  activate CG
  CG->>SK: AggiornaScheletro(animazione)
  activate SK
  SK->>SK: RuotaOssa(angoli)
  SK-->>CG: PosizioneCilindri(coordinate3D)
  deactivate SK

  CG->>HC: VerificaCollisione3D(cilindri, avversario)
  activate HC
  HC->>HC: CalcolaOrientamentoZ(asseZ)

  alt Mossa lineare
    HC->>HC: VerificaAllineamento(cilindro, bersaglio)
    alt Avversario allineato
      HC-->>CG: ColpoValido()
    else Avversario in sidestep
      HC-->>CG: ColpoMancato()
    end
  else Mossa homing
    HC->>HC: CreaParete360gradi()
    HC-->>CG: ColpoValido()
    Note right of HC: Parete tridimensionale a 360°\ncattura il sidestep
  end

  deactivate HC
  CG->>AV: ApplicaEffetto(danno, stato)
  deactivate CG

    Diagrammi di Stato

    Stato 1 — Ciclo di vita di una hitbox in Smash Ultimate

    stateDiagram-v2
  [*] --> Inattiva : Personaggio in idle

  Inattiva --> Generata : Giocatore esegue input attacco
  Generata --> Attiva : Frame di attivazione raggiunto
  Attiva --> ColpitoValido : D < R1 + R2
  Attiva --> ColpitoMancato : D >= R1 + R2
  Attiva --> Interpolata : Mossa troppo rapida\nbullet-through-paper rilevato
  Interpolata --> ColpitoValido : Sfera interpolata colpisce
  Interpolata --> ColpitoMancato : Nessun contatto
  ColpitoValido --> DannoApplicato : Applica danno e knockback
  ColpitoMancato --> Esaurita : Fine durata animazione
  DannoApplicato --> Esaurita : Fine durata animazione
  Esaurita --> Inattiva : Reset personaggio

    Stato 2 — Ciclo di vita di una hitbox in Tekken 8

    stateDiagram-v2
  [*] --> Inattiva : Lottatore in guardia o idle

  Inattiva --> AncoraggioScheletro : Input attacco ricevuto
  AncoraggioScheletro --> AggiornamentoPosizione : Scheletro 3D aggiornato ogni frame
  AggiornamentoPosizione --> AggiornamentoPosizione : Animazione in corso\nhitbox segue le ossa

  AggiornamentoPosizione --> VerificaLineare : Mossa lineare attivata
  AggiornamentoPosizione --> VerificaHoming : Mossa homing attivata

  VerificaLineare --> ColpoBersaglio : Avversario allineato sull'asse Z
  VerificaLineare --> ColpoSchivato : Avversario in sidestep
  VerificaHoming --> ColpoBersaglio : Parete 360° intercetta
  VerificaHoming --> ColpoBersaglio : Sidestep non sufficiente

  ColpoBersaglio --> DannoApplicato : Calcolo danno e stato
  ColpoSchivato --> Esaurita : Fine durata
  DannoApplicato --> Esaurita : Fine durata
  Esaurita --> Inattiva : Reset lottatore

  actor_p(["Giocatore"])
  actor_m(["Motore di Gioco"])

  UC1([Esegui mossa d'attacco])
  UC2([Calcola distanza D tra sfere])
  UC3([Verifica D < R1 + R2])
  UC4([Valida il colpo])
  UC5([Applica danno e knockback])
  UC6([Interpola sfere anti bullet-through-paper])

  actor_p --> UC1
  UC1 --> UC2
  UC2 --> UC3
  UC3 --> UC4
  UC4 --> UC5
  UC3 -->|"mossa troppo veloce"| UC6

  actor_m --> UC2
